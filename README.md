# 28卒・文系からねらうIT企業ガイド

28卒の文系就活生向けに、IT業界の上場企業を数字で比べる単一HTMLのページです。

- 公開URL: https://shuyaofficial.github.io/it-company-guide/
- 載せている会社: 上場企業のみ（131社。狙い目24社、大手・難関12社を選んで紹介）
- 上場していない会社、外資系の日本法人、コンサル会社などは載っていません。

## 出典とデータ時点

- 会社四季報 業界地図 2027年版（東洋経済新報社）: 業界の天気予想、市場規模、主要企業、時価総額ランキング（2026年6月末時点）
- 会社四季報 2026年4集（26年6月時点のデータ）（東洋経済新報社）: 従業員数、平均年齢、平均年収、自己資本比率、営業利益率、売上高と予想の数値
- 就活の教科書（reashu.com）: 就職難易度。サイト独自の見方です。
- 四季報の記者コメント・特色・見出しの文章は載せていません。「なぜおすすめか」は数字から機械的に作り、「どんな会社か」は誌面の事業内容をもとに自分の言葉で書いた短文です。
- ページ作成日: 2026-10-18

## 注意

- このページは就職の助言ではありません。入りやすさは誌面の数字から機械的に出した推定です。
- 採用人数・倍率・募集職種は、各社の採用ページや説明会で確かめてください。
